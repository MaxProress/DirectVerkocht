# DirectVerkocht

Website voor DirectVerkocht. Plain HTML/CSS/JS, geen build step.

## Structuur

- `index.html` — homepage
- `assets/css/` — stylesheets
- `assets/js/` — scripts
- `assets/img/` — afbeeldingen

## Lokaal bekijken

Open `index.html` in de browser, of start een simpele server:

```
python3 -m http.server 3000
```

## Deploy

Gekoppeld aan Vercel. Elke push naar `main` deployt automatisch.
